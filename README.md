# 🐍 Java Snake Game

A modular, object-oriented Snake game clone built in Java with:
- Delta time game loop
- `Entity` superclass with `Snake` and `Apple` subclasses
- Clean separation of concerns
- Custom panel rendering with Swing

## Features
- Smooth movement using delta time
- Apple spawning and growth mechanics
- Collision detection
- Score tracking

## How to Run
1. Ensure you have Java JDK 8+ installed
2. Compile: `javac main.java`
3. Run: `java main`
